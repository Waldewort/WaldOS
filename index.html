Command Structure

1. Window Controls (Open / Close / Maximize)

To control app windows, start with the action verb followed by the app name:

[Action] + [App Name]

Action keywords: Open, Close, Maximize, Restore
2. In-App Actions (Search, Write, Calculate)

To execute an action inside a specific app, always state the app name or trigger word first, followed by the action and your content:

[App Name] + [Action / Function] + [Your Content or Input]

Structure: Target App ➔ Desired Function ➔ Query / Text / Calculation
3. Global Commands

Use global system triggers to affect the whole workspace at once:

"Close All" — Closes all currently open windows immediately.
